ข้อควรรู้
  - ใช้ Chrome หรือ Edge  เมื่อเปิดจากไฟล์ เบราว์เซอร์อาจถามสิทธิ์กล้องทุกครั้งที่เปิดหน้า
  - ตรรกะในหน้าเว็บย้ายมาจากโค้ด Python ตรง ๆ (exercise_loader, 1.2 detect, 1.3, 1.4, 1.5, main.py, pose_core, 4.1-4.4)
    จึงมีข้อจำกัดเดียวกับระบบ 1: วัดมุมจากภาพ 2 มิติ เหมาะกับท่าที่หันหน้าเข้ากล้อง
    และเอียงซ้ายกับเอียงขวาแยกกันไม่ออก (มุมลำตัวไม่แยกข้าง)
  - ท่าใหม่ที่เพิ่มใน exercises.json ใช้กับคนจำลองได้เลย (คนจำลองสร้างจากนิยามมุม/เกณฑ์ของท่า)
    ใช้ชื่อมุมตามที่คนจำลองรู้จัก (ดูรายการด้านบน) ท่าที่ใช้ชื่ออื่นยังเล่นได้ด้วยกล้องจริง แต่คนจำลองจะไม่ขยับตามมุมนั้น
  - ถ้าจะให้เครื่องอื่นเปิดผ่านเซิร์ฟเวอร์กลางของวิทยาลัย ต้องเป็น HTTPS (หรือ localhost) เบราว์เซอร์จึงยอมให้ใช้กล้อง
  - ไลบรารี MediaPipe Tasks Vision (Apache-2.0) ใน vendor\ ฝังมาในรูปสคริปต์เดียวเพื่อให้เปิดแบบไฟล์ได้
