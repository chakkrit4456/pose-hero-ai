      เครื่องมือ

      ทดสอบความเร็วตอบสนอง — เหยียบตามแผ่นที่เรืองแสงสีแดง 10 ครั้ง

      ค่าดิบจากอุปกรณ์ / ประวัติ (สำหรับตรวจปัญหา)

      🔘 เปิดหน้าทดสอบปุ่มแป้นเต้น (ดูทุกปุ่ม/แกนแบบละเอียด)

      –
      นำไปใช้ร่วมกับระบบอื่น

      ระบบอ่านแผ่นเต้นแยกเป็นไฟล์ dancepad.js (ไม่มี UI ไม่พึ่งไลบรารี) เรียกใช้ในหน้าเว็บอื่นได้ทันที:

      <script src="dancepad.js"></script>
<script>
  const pad = DancePad.create();
  pad.on('press',   e => console.log('เหยียบ',  e.id, e.name));   // id: x u o l r tri d sq
  pad.on('release', e => console.log('ปล่อย', e.id));
  pad.start();
</script>

      ส่งสัญญาณข้ามหน้า/แท็บ/iframe อัตโนมัติ — ระบบอื่นไม่ต้องโหลดไฟล์ก็รับได้:

      addEventListener('dancepad:press', e => use(e.detail.id));          // หน้าเดียวกัน
new BroadcastChannel('dancepad').onmessage = e => use(e.data);      // แท็บอื่น (origin เดียวกัน)
addEventListener('message', e => e.data.source==='dancepad' && use(e.data)); // ฝัง iframe

      ฝังหน้านี้เป็นตัวตั้งค่า/แผงแสดงผลในระบบอื่น: <iframe src="ส่วน ระบบ/index.html?embed=1"> — ค่าที่ตั้งไว้จะถูกใช้ร่วมกันทุกหน้าที่อยู่ origin เดียวกัน (ควรเปิดผ่านเซิร์ฟเวอร์เดียวกัน เช่น Live Server)
