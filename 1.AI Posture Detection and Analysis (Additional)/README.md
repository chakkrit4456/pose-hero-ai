# ระบบ AI ตรวจจับและวิเคราะห์ท่าทาง (Move & Relieve AI)

## ภาพรวมการทำงานร่วมกัน

```
exercises.json ──► exercise_loader.py (โหลด + ตรวจสอบข้อมูลท่า)
                          │
                          ▼
                       main.py  (ควบคุมเกม: เมนู → นับถอยหลัง → ทำท่า → พัก → สรุปผล)
                          │
   ┌──────────────────────┼──────────────────────────────────────────────┐
   ▼                      ▼                ▼               ▼             ▼
 1.1 กล้อง ─ภาพ─► 1.2 ร่างกาย ─จุด─► 1.3 ข้อต่อ ─ข้อต่อ─► 1.4 วิเคราะห์ ─มุม/จำนวนครั้ง─► 1.5 ประเมิน
                                                                                          │
                                                                  คะแนน + คำแนะนำ ──► แสดงบนหน้าจอ (overlay.py)
```

| ไฟล์ | หน้าที่ |
|---|---|
| `1.1 Camera Input System.py` | คลาส `CameraSystem`: ค้นหา/เลือก/เปิด/ปิดกล้อง ส่งภาพด้วย `get_frame()` (คืน None ถ้าอ่านไม่ได้) หรือ `read()` (แจ้ง CameraError) กลับภาพกระจก มีเมนูทดสอบในตัว |
| `1.2 Body Detection System.py` | คลาส `BodyDetectionSystem`: `detect()` ส่งตำแหน่งข้อต่อ 33 จุดให้ระบบ 1.3 และเช็กว่าอยู่ในกรอบครบหรือไม่ / `process_frame()` และ `run(camera)` วาดโครงกระดูกไว้ทดสอบเดี่ยว ๆ รองรับ MediaPipe ทั้งรุ่นเก่าและรุ่นใหม่ |
| `1.3 Joint Detection System.py` | แปลงเป็นพิกเซล ลดอาการสั่น สร้างข้อต่อเสมือน วาดโครงกระดูก |
| `1.4 Posture Analysis System.py` | คำนวณมุมข้อต่อ นับจำนวนครั้ง จับเวลาค้างท่า |
| `1.5 Posture Assessment System.py` | เทียบมุมกับเกณฑ์ ให้คะแนนรายครั้ง/รวม และคำแนะนำภาษาไทย |
| `main.py` | ตัวรันหลักที่เชื่อมทุกระบบ |
| `system_loader.py` | ให้ไฟล์ระบบเรียกหากันได้ผ่านเลขระบบ เช่น `load_system("1.2")` |
| `exercise_loader.py` | โหลดและตรวจสอบ `exercises.json` (ใช้ร่วมกับระบบจัดการท่าบริหาร) |
| `overlay.py` | วาดข้อความภาษาไทย แถบความคืบหน้า ลงบนภาพ |
| `exercises.json` | ท่าบริหารตัวอย่าง 5 ท่า |
| `test_all_systems.py` | ทดสอบทุกระบบรวมกันโดยไม่ต้องใช้กล้อง |

## ติดตั้ง

1. ติดตั้ง Python 3.10+ (ติ๊ก Add Python to PATH)
2. เปิด Command Prompt ในโฟลเดอร์นี้ แล้วรัน `pip install -r requirements.txt`
3. ครั้งแรกที่รัน ระบบ 1.2 จะดาวน์โหลดโมเดลตรวจจับท่าทางอัตโนมัติ (ประมาณ 6 MB ต้องมีอินเทอร์เน็ต)
   ถ้าดาวน์โหลดไม่ได้ โปรแกรมจะบอกลิงก์และตำแหน่งที่ต้องนำไฟล์ไปวาง (โฟลเดอร์ `models`)

## วิธีใช้

```
python test_all_systems.py          ทดสอบว่าทุกระบบทำงานร่วมกันได้ (ไม่ต้องมีกล้อง)
python "1.1 Camera Input System.py"   เมนูทดสอบ 1) กล้อง 2) ตรวจจับร่างกาย (1.1 + 1.2)
python main.py                      เล่นจริง เลือกหมวดหมู่/ท่าจากเมนู
python main.py --all                ทำทุกท่าต่อกัน
python main.py --exercise arm_01    ทำท่าที่ระบุ
python main.py --camera 1           ใช้กล้องหมายเลข 1 (ไม่ระบุ ระบบค้นหาให้ ถ้ามีหลายตัวจะถามให้เลือก)
```
ปุ่มระหว่างเล่น: `n` = ข้ามท่า/ข้ามช่วงพัก, `q` หรือ `ESC` = ออก

## คำแนะนำการตั้งกล้อง
- วางกล้องหรือเว็บแคมระดับอก-เอว ให้เห็นทั้งตัว ยืนห่างประมาณ 2-3 เมตร หันหน้าเข้ากล้อง
- แสงสว่างพอ ไม่ย้อนแสง สวมเสื้อผ้าที่เห็นรูปร่างชัด
- ระบบวัดมุมจากภาพ 2 มิติ จึงออกแบบสำหรับท่าที่หันหน้าเข้ากล้อง

## รูปแบบข้อมูลท่า (exercises.json)
ระบบจัดการท่าบริหารควรบันทึกข้อมูลในรูปแบบเดียวกันนี้ไว้ที่ `2.Exercise Management System (Additional)/data/exercises.json`
ระบบ AI จะเลือกใช้ไฟล์นั้นก่อนโดยอัตโนมัติ

```json
{
  "id": "arm_01", "name": "ยกแขนด้านข้าง", "category": "แขนและไหล่",
  "description": "...", "steps": ["..."], "precautions": ["..."], "muscles": ["..."],
  "image": "images/arm_01.png",
  "reps": 10, "duration_sec": 0, "rest_sec": 15,
  "tracked_joints": ["left_shoulder", "left_elbow", "left_hip", "..."],
  "angles":  { "left_shoulder": ["left_hip", "left_shoulder", "left_elbow"] },
  "counter": { "mode": "reps", "angle": ["left_shoulder", "right_shoulder"],
               "start_angle": 15, "target_angle": 90 },
  "criteria": [
    { "angle": "left_shoulder", "min": 75, "max": 105, "when": "target",
      "feedback_low": "ยกแขนให้สูงขึ้นอีกหน่อย", "feedback_high": "แขนสูงเกินระดับไหล่" }
  ]
}
```
- `angles` : มุมที่วัด แต่ละมุมระบุข้อต่อ 3 จุด [จุดแรก, จุดมุม, จุดสุดท้าย] ใช้ข้อต่อเสมือนได้ (`mid_shoulder`, `mid_hip`, `below_mid_hip`)
- `counter` : มุมที่ใช้นับครั้ง จาก `start_angle` ไป `target_angle` แล้วกลับมา = 1 ครั้ง (`mode: "hold"` + `hold_sec` = ค้างท่า)
- `criteria` : เกณฑ์ให้คะแนน `when: "target"` ตรวจตอนทำท่าได้สูงสุด `when: "always"` ตรวจตลอดการทำท่า
- หมวดหมู่ที่ใช้ได้: แขนและไหล่ / ลำตัวและเอว / ขาและสะโพก / การยืดเหยียดร่างกาย
- ท่าที่ข้อมูลผิดจะถูกข้ามพร้อมบอกเหตุผล ไม่ทำให้โปรแกรมล้ม

## แก้ปัญหาเบื้องต้น
| อาการ | วิธีแก้ |
|---|---|
| เปิดกล้องไม่ได้ | ปิด Zoom/Line/Teams, เปิดสิทธิ์กล้องใน Windows, ลอง `--camera 1` |
| ข้อความไทยบนจอไม่ขึ้น | วางไฟล์ฟอนต์ไทย `.ttf` ไว้ในโฟลเดอร์ `fonts` |
| ดาวน์โหลดโมเดลไม่ได้ | ดาวน์โหลดไฟล์ตามลิงก์ที่โปรแกรมแจ้ง ไปวางที่ `models/pose_landmarker_lite.task` |
| นับครั้งไม่ขึ้น | ท่าอาจไม่ถึงมุมเป้าหมาย ปรับ `target_angle` / `reach_ratio` ใน exercises.json ให้เหมาะกับคนเล่น |
| ซ้าย-ขวากลับกัน | ลองรันด้วย `--no-mirror` เทียบดู แล้วแจ้งผล |

## ข้อควรทราบ
ค่ามุมและเกณฑ์ในไฟล์ตัวอย่างเป็นค่าเริ่มต้นที่คำนวณจากท่าสังเคราะห์ ควรปรับจูนกับผู้เล่นจริงหลายรูปร่าง
และไม่ใช่คำแนะนำทางการแพทย์ ผู้มีอาการเจ็บป่วยควรปรึกษาแพทย์หรือนักกายภาพบำบัดก่อนออกกำลังกาย
