โฟลเดอร์เพลงประกอบเกม (Move & Relieve)
=======================================
วางไฟล์เพลงของคุณในโฟลเดอร์นี้ แล้วรัน build ใหม่ 1 ครั้ง:

    node "3.Game Control System/build.js"      (หรือ  npm run build)

เกมจะสแกนโฟลเดอร์นี้เอง และเล่นเพลงวนต่อกันตอนเล่นเกม
  - เริ่มเล่นเมื่อเริ่มท่าแรก  หยุดชั่วคราวตามปุ่ม "หยุด"  หยุดเมื่อจบเกม
  - เสียงเบากว่าเสียงนับถอยหลัง/เสียงพูด (ประมาณ 35% ของระดับเสียงที่ตั้งไว้) ปรับที่ตั้งค่า → เสียง
  - เลือกเพลงได้ที่หน้า "เลือกท่า" ก่อนเริ่มเกม: สุ่มวนทุกเพลง / เพลงเดียววนซ้ำ / ไม่เปิดเพลง (มีปุ่มฟังตัวอย่าง)
  - ระหว่างเล่นมีปุ่ม "เพลงถัดไป" (เมื่อเลือกสุ่มวนทุกเพลง)

เพลงตามจังหวะ (โหมด "อัตโนมัติ" ในหน้าเลือกท่า)
  วางเพลงแยกโฟลเดอร์ย่อย แล้วเกมจะเลือกให้ตามท่าที่กำลังเล่นและระดับความยาก และเปลี่ยนเพลงเองเมื่อท่าถัดไปต้องการจังหวะอื่น
    Music/slow   เพลงปกติ  -> ระดับ "ง่าย"     และโหมดนักเต้นเท้าไฟระดับ "อุ่นเครื่อง"
    Music/mid    เพลงกลาง  -> ระดับ "ปานกลาง"  และโหมดนักเต้นเท้าไฟระดับ "ร้อนแรง"
    Music/fast   เพลงเร็ว   -> ระดับ "ยาก"      และโหมดนักเต้นเท้าไฟระดับ "ลุกเป็นไฟ"
  ไฟล์ที่วางใน Music ตรง ๆ (ไม่อยู่ในโฟลเดอร์ย่อย) ถือเป็นเพลงทั่วไป ใช้แทนเมื่อกลุ่มนั้นยังไม่มีเพลง
  ถ้าไม่มีโฟลเดอร์ย่อยเลย ตัวเลือก "อัตโนมัติ" จะไม่แสดง (ใช้ "สุ่มวนทุกเพลง" แทน)

รองรับไฟล์: .mp3  .ogg  .wav  .m4a  .aac  .flac  .opus
ถ้าโฟลเดอร์ว่าง เกมจะไม่มีเพลง (ใช้งานได้ตามปกติ)

คำแนะนำเรื่องลิขสิทธิ์
  - ใช้เพลงที่คุณมีสิทธิ์ใช้ เช่น เพลงที่ซื้อ/สร้างเอง หรือเพลงฟรีที่อนุญาตให้ใช้ (Creative Commons, Pixabay Music,
    YouTube Audio Library, Free Music Archive) และตรวจเงื่อนไขการให้เครดิตของแต่ละเพลง
  - ถ้าเผยแพร่เกมให้ผู้อื่น อย่าใส่เพลงที่ไม่มีสิทธิ์เผยแพร่

เลือกเพลงที่เหมาะกับการออกกำลังกายเบา ๆ: จังหวะประมาณ 90-120 BPM ไม่มีเนื้อร้องที่กลบเสียงพูดของเกม
ชื่อไฟล์ภาษาไทยหรือมีช่องว่างได้ แต่แนะนำให้สั้น
