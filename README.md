# Move & Relieve — เกมบริหารร่างกายสำหรับคนทำงานออฟฟิศ

เกมออกกำลังกายที่ใช้ **AI จับท่าทางจากกล้อง** (MediaPipe) นับครั้ง ให้คะแนนความถูกต้อง แนะนำการแก้ท่า แล้วสรุปผลพร้อมสถิติสะสม
รันในเบราว์เซอร์ (Chrome / Edge) ได้ทั้งออนไลน์และออฟไลน์ ไม่ต้องมีเซิร์ฟเวอร์

## เริ่มใช้งาน

1. เปิดไฟล์ `3.Game Control System/Game Start.html` ด้วย Chrome หรือ Edge (ดับเบิลคลิกได้เลย)
2. กด **เริ่ม** → เลือกท่า → **เริ่มเกม** กล้องจะเปิดเองและขอสิทธิ์ใช้กล้องครั้งแรก (กดอนุญาต)
3. ยืนให้เห็นทั้งตัวในภาพ เกมจะให้ดูท่าตัวอย่างก่อนแต่ละท่า แล้วนับถอยหลังและเริ่มนับครั้ง

> ท่าที่มีคำว่า **AI** ตรวจด้วยกล้องได้ ท่า "ท่าของฉัน" (ที่สร้างเอง) ต้องกดปุ่ม **+1 ครั้ง** เอง
> ท่า AI ทั้งหมด 17 ท่า: พื้นฐาน 10 ท่า + เอียงคอ · หมุนไหล่ · ยืดแขนเหนือศีรษะ · นั่งบิดลำตัว + ท่าทดลอง (ยืดบ่า · ยืดข้อมือ · หมุนข้อมือ ใช้ตำแหน่งนิ้วชี้ ความแม่นขึ้นกับกล้องและแสง) (นิยามอยู่ที่ `Web Testing System/data/src/exercises.json`)

## Build

`Game Start.html` สร้างจาก `Game Start.template.html` + โมดูล 2.x / 6.x / 7.x:

```
node "3.Game Control System/build.js"      # หรือ  npm run build
```

build จะซิงก์ไฟล์ `ai/` จาก `Web Testing System` ให้อัตโนมัติ (ถ้าไฟล์ต้นฉบับใหม่กว่า) **แก้โค้ดเกมที่ template และโมดูล ไม่ใช่ที่ `Game Start.html`**

## ทดสอบ

```
node tests/run-tests.js      # หรือ  npm test
```

ทดสอบระบบเกม แจ้งเตือน สรุปผล ประวัติ และระบบ AI ด้วย "คนจำลอง" ที่ทำท่าตามนิยามของแต่ละท่า (ไม่ได้ใช้กล้องจริง)
ส่วนที่ต้องลองบนเครื่องจริง: กล้อง MediaPipe และความแม่นของค่าองศาในแต่ละท่า

## ปรับค่าท่าให้ตรงกับกล้องของคุณ

ท่าก้มตัว บิดลำตัว และยกเข่า วัดจากกล้อง 2 มิติด้านหน้า ค่าองศาอาจต้องปรับตามตำแหน่งยืน:

1. ตั้งค่า → ติ๊ก **แสดงค่ามุมสดตอนเล่น (ไว้ปรับท่า)**
2. เล่นท่านั้น ดูค่ามุมสดและค่า "เป้าหมาย: เริ่ม X° → ถึง Y°" ที่ขึ้นข้างปุ่ม
3. แก้ `start_angle` / `target_angle` / `criteria` ของท่านั้นใน `Web Testing System/data/src/exercises.json`
4. รัน `Prepare Web Test Files.bat` (สร้าง `exercises-data.js`) แล้ว build ใหม่

## เพิ่มท่าใหม่

- **ท่าที่ผู้เล่นสร้างเอง:** หน้าหลัก → **จัดการท่า** → สร้าง/แก้ไขท่า (ลากโครงกระดูก) ท่าจะไปอยู่ในหน้า "เริ่ม" ในชื่อ "ท่าของฉัน" (กดนับเอง)
- **ท่าที่ AI ตรวจได้:** เพิ่มท่าใน `Web Testing System/data/src/exercises.json` (รูปแบบเดียวกับ `exercises.json` ของระบบ 1: `angles`, `counter`, `criteria`) รัน `Prepare Web Test Files.bat` เพื่อสร้าง `exercises-data.js` แล้วเพิ่มบรรทัดในแคตตาล็อกของ `3.Game Control System/2.2 Exercise Selection.js` (id ต้องตรงกัน) แล้ว build ใหม่ หน้าเกมจะติดป้าย AI ให้เองเมื่อ id มีในข้อมูล
- **ท่าที่กล้องตรวจไม่ได้** (เช่น เก็บคางแก้คอยื่น, ประสานมือไว้ด้านหลัง) ถูกเอาออกจากเกมแล้ว เพราะกล้องหน้าวัดไม่ได้ ถ้าจะเพิ่มกลับ ให้ใส่ในแคตตาล็อก 2.2 และเพิ่มข้อมูลแอนิเมชันตัวอย่างในอ็อบเจกต์ `DESK` ของ template (กดนับเองด้วยปุ่ม +1)

## การตั้งค่าในเกม

## ข้อจำกัดที่ทราบ

- ท่าตัวอย่างของ "ท่าของฉัน" ใช้โครงกระดูกแบบลำตัว แขน ขา (ไม่มีศีรษะ/นิ้ว) ส่วนท่า AI ใช้ตัวละครสอนเต็มตัวที่ทำท่าเดียวกับที่ AI ตรวจ
- เสียงพูดภาษาไทยขึ้นกับเสียงที่ติดตั้งในเบราว์เซอร์/ระบบปฏิบัติการ ถ้าไม่มีจะเงียบ (ข้อความและเสียงบี๊บยังทำงาน)
- ต้องใช้เบราว์เซอร์ที่รองรับ `getUserMedia` และ WebAssembly (Chrome / Edge รุ่นใหม่) และเปิดผ่านไฟล์ในเครื่อง, localhost หรือ https

## ขึ้นเว็บ

กล้องของเบราว์เซอร์ใช้ได้เฉพาะหน้าเว็บ **https** (หรือ localhost) จึงต้องขึ้นเว็บถ้าจะให้คนอื่นเปิดเล่นจากลิงก์

```
node "3.Game Control System/build-web.js"               # สร้าง dist/ (ไม่รวมเพลง)
node "3.Game Control System/build-web.js" --with-music  # รวมเพลงใน Music/ (ใช้เมื่อมีสิทธิ์เผยแพร่เพลงนั้นจริง ๆ)
```

`dist/` มี `index.html` + `ai/` + manifest + service worker (เปิดครั้งแรกแล้วใช้ออฟไลน์ได้ และ "ติดตั้งเป็นแอป" บนมือถือได้) ขนาดประมาณ 20 MB (เซิร์ฟเวอร์ส่วนใหญ่บีบ gzip ให้เอง)

**GitHub Pages (อัตโนมัติ):** repo มี workflow `.github/workflows/pages.yml` ใช้งานโดย
1. push โค้ดขึ้น GitHub
2. ใน repo: Settings → Pages → Build and deployment → Source เลือก **GitHub Actions**
3. ทุกครั้งที่ push เข้า `main` ระบบจะ build + ทดสอบ + ขึ้นเว็บให้ ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

**ทำเอง:** รัน `build-web.js` แล้วอัปโหลดเนื้อหาใน `dist/` ไปยังโฮสต์ใดก็ได้ที่เป็น https (Netlify, Cloudflare Pages ฯลฯ ลากโฟลเดอร์ `dist` ไปวางได้เลย)

> เพลงใน `Music/` ถูกเก็บใน git และขึ้นเว็บด้วย ส่วนไฟล์ที่สร้างจาก build (`ai/`, `music-list.js`, `dist/`) ไม่ถูกเก็บ — หลัง clone ให้รัน `node "3.Game Control System/build.js"` ก่อนเปิด `Game Start.html`

## แยกโหมดท่ากับโหมดแผ่นเต้น

โหมดท่าออกกำลังกายใช้กล้อง/AI อย่างเดียว ไม่มีระบบเหยียบแผ่นปนอยู่ในหน้าเล่น ส่วนแผ่นเต้นเล่นได้ที่ **โหมดแผ่นเต้น** และ **โหมดนักเต้นเท้าไฟ** (แต่ละโหมดมีปุ่มตั้งค่าแผ่นของตัวเอง)
AI จับท่ารันใน Web Worker แยกจากหน้าเกม (ถ้าเบราว์เซอร์ใช้ Worker ไม่ได้ จะกลับไปรันในหน้าเกมเอง)

## สลับต่อเนื่อง: จบท่าบริหารแล้วต่อด้วยโหมดเหยียบ

เมื่อทำชุดท่าบริหารจบ (ไม่ได้กดออกกลางคัน) เกมพาไปหน้า "จบท่าบริหารแล้ว" แสดงคะแนนท่าบริหาร พร้อมบอกว่าจะต่อด้วยโหมดเหยียบระดับไหน นับถอยหลัง 10 วินาทีแล้วเริ่มเอง หรือกด **เริ่มเลย** / **ดูสรุปท่าบริหารก่อน** / **ข้ามโหมดเหยียบ** จบโหมดเหยียบแล้วจบเลย (ไม่วนกลับ) ปิดฟีเจอร์ได้ที่ตั้งค่า → "จบท่าบริหารแล้วต่อด้วยโหมดเหยียบ"

- **เลือกระดับให้เองจากง่ายไปยาก** (`6.Dance Game/8.6 Step Ladder.js`): แผ่นเต้น ง่าย → ปานกลาง → ยาก → เท้าไฟ อุ่นเครื่อง → ร้อนแรง → ลุกเป็นไฟ เริ่มที่ขั้นแรก ได้ 70+ คะแนนขึ้นขั้นถัดไป ต่ำกว่า 40 ลดหนึ่งขั้น อยู่ระหว่างนั้นเล่นขั้นเดิม (ขั้นเก็บในเครื่อง)
- โหมดเท้าไฟต้องใช้แผ่นเต้นจริงที่ตั้งค่าครบ ถ้าขั้นของคุณถึงเท้าไฟแต่ไม่พบแผ่น เกมให้เล่นแผ่นเต้นระดับยากแทน (ไม่ปรับขั้น)
- **คะแนนแยกกัน:** ท่าบริหารมีเกรดและการ์ดแชร์ของมัน โหมดเหยียบมีคะแนนและการ์ดของมันเอง ย้อนไปดูสรุปท่าบริหารได้จากปุ่มบนหน้าผลของโหมดเหยียบ
- สองโหมดยังแยกโค้ดจากกัน: ตัวเชื่อมแค่เปิดโหมดถัดไปให้เมื่อโหมดแรกจบ

## โหมดนักเต้นเท้าไฟ

หน้าหลัก → **โหมดนักเต้นเท้าไฟ** เล่นด้วยแผ่นเต้น USB เท่านั้น (ไม่ใช้กล้อง/AI) ยืนกลางแผ่น แล้วเหยียบแผ่นเมื่อไอคอนที่พุ่งจากจุดกลางไปแตะแผ่นนั้น กระดานบนจอตรงกับตำแหน่งแผ่นจริง

- **เล่นรอบละ 3 นาที:** จบตามเวลา มีนาฬิกานับถอยหลังและเสียงเตือน 10 วินาทีสุดท้าย (แผ่นหลุด เวลาจะหยุดรอ)
- **3 ระดับ:** อุ่นเครื่อง (ลูกศร 4 แผ่น, 90 BPM) · ร้อนแรง (ครบ 8 แผ่น, 120 BPM) · ลุกเป็นไฟ (ครบ 8 แผ่น, 150 BPM, เหยียบคู่บ่อย) ก้าวสลับเท้าซ้าย-ขวาโดยไม่ต้องไขว้ขา
- **เกจความร้อน:** เหยียบแม่นแล้วเกจเพิ่ม พลาดแล้วเกจลด เมื่อเต็มจะเข้าช่วง **ไฟลุก** 8 วินาที คะแนน ×2
- **เปลวไฟตามคอมโบ:** ไฟเริ่มติดที่คอมโบ 3 ยิ่งสแต็กยิ่งลุกสูงจนลุกโชนที่คอมโบ 30 คอมโบขาดแล้วไฟมอดลง (ถ้าเครื่องตั้งค่าลดการเคลื่อนไหว ไฟจะเบาลง)
- **เพลง:** เลือกได้ที่เมนูก่อนเริ่ม — อัตโนมัติตามระดับ (อุ่นเครื่อง → `Music/slow` · ร้อนแรง → `Music/mid` · ลุกเป็นไฟ → `Music/fast`) · สุ่มทุกเพลง · เลือกเพลงเดียว · ไม่เปิดเพลง พร้อมปุ่มฟังตัวอย่าง เมื่อมีเพลงจะปิดกลองในเกม ถ้าไม่มีเพลงหรือปิดเพลงไว้จะใช้กลองสังเคราะห์ที่ตรงกับเวลาก้าวแทน จังหวะก้าวเป็นไปตาม BPM ของระดับ ไม่ได้ซิงก์กับจังหวะของไฟล์เพลง
- แผ่นหลุดกลางเกม เกมจะหยุดรอจนกว่าจะเสียบใหม่ · จบรอบมีคะแนน ฉายา การ์ดแชร์ และสถิติสูงสุดแยกตามระดับ · โค้ดอยู่ที่ `6.Dance Game/8.5 Fire Feet.js`

## โหมดแผ่นเต้น

หน้าหลัก → **โหมดแผ่นเต้น** เป็นเกมอีกแบบที่แยกจากโหมดท่าออกกำลังกาย (ไม่ใช้กล้อง/AI): เหยียบแผ่นที่สว่างเป็นสีแดงให้ตรงจังหวะ

- **เล่นได้ 3 แบบ:** แผ่นเต้น USB (ผ่าน Gamepad API ของเบราว์เซอร์ Chrome/Edge) · คีย์บอร์ด (`Q` `↑` `E` / `←` `→` / `Z` `↓` `C` ตามตำแหน่งแผ่น) · แตะแผ่นบนหน้าจอ
- **ตั้งค่าแผ่นครั้งแรก:** กด "ตั้งค่าแผ่น" แล้วทำตามที่ระบบบอก (ค่าจะถูกจำไว้ในเบราว์เซอร์ และใช้ร่วมกับหน้าตั้งค่าแบบละเอียด `dance/index.html` ได้) ถ้าเจอปัญหาเรื่องแผ่น ใช้หน้าตรวจสอบแบบละเอียดที่ลิงก์ในหน้าเกม
- **3 ระดับ:** ง่าย (ก้าวละ 1.5 วินาที, 24 ก้าว) · ปานกลาง (1 วินาที, 36 ก้าว, มีก้าวคู่บ้าง) · ยาก (0.75 วินาที, 48 ก้าว, ก้าวคู่บ่อย)
- **ตัดสิน:** PERFECT ±120 ms · GREAT ±220 ms · GOOD ±350 ms · ไม่เหยียบ = MISS มีคอมโบคูณคะแนน (สูงสุด x2) ความแม่นยำใช้คิดเกรดเกณฑ์เดียวกับโหมดท่า (85/70/50)
- **เพลงประกอบ (ไม่บังคับ):** ติ๊ก "เล่นเพลงประกอบ" ได้ แต่เพลงไม่ซิงค์กับจังหวะเกม (จังหวะเกมมีเสียงเมโทรนอมเบา ๆ ให้ตามอยู่แล้ว)
- เมื่อจบ: คะแนน เกรด สถิติ คำแนะนำ การ์ดแชร์ (เหมือนโหมดท่า) และคะแนนสูงสุดแยกตามระดับ (เก็บในเครื่อง)

ต้นฉบับระบบอ่านแผ่นอยู่ที่โฟลเดอร์ `ส่วน ระบบ` (แก้ที่นั่นแล้วรัน build) — build ซิงก์ `dancepad.js`, หน้าตั้งค่า และรูปจากโฟลเดอร์ `รูป` ให้ไปไว้ใน `3.Game Control System/dance/` และ `dist/dance/`

## ระบบสุขภาพและความสะดวก

- **ข้อความเตือนสุขภาพ** (9.1): ขึ้นตอนเปิดครั้งแรก (และเมื่อเนื้อหาเปลี่ยนรุ่น) บอกว่าไม่ใช่การรักษา ให้หยุดถ้าเจ็บ/ชา/เวียนศีรษะ ปรึกษาแพทย์ถ้ามีโรคประจำตัว และบอกชัดว่าภาพกล้องไม่ถูกบันทึกหรือส่งออก อ่านซ้ำได้ที่ตั้งค่า
- **ชุดท่าด่วน** (9.2): ปุ่มใหม่ในหน้าหลัก 6 ชุด (แก้ปวดคอ-บ่า, ก่อนประชุม, พักข้อมือ-แขน, ยืดหลัง-เอว, ปลุกขา-สะโพก, ยืดทั้งตัว) กด "เริ่มเลย" เริ่มเล่นทันที หรือ "ดู/แก้ก่อนเริ่ม" เพื่อปรับในหน้าเลือกท่า ระบบประมาณเวลาให้ตามระดับความยากที่เลือก
- **ตัวช่วยตั้งกล้อง** (9.6): ปุ่ม "ตรวจตำแหน่งกล้อง" ในหน้าเลือกท่าและชุดท่าด่วน เปิดกล้องสดแล้วเช็กลิสต์ ✓/✗ ว่าเห็นไหล่/สะโพก ระยะห่างพอดีไหม ยืนกลางภาพไหม พร้อมบอกวิธีแก้ (ต้องมีระบบ AI)
- **บันทึกอาการปวด** (9.4): เลื่อนระดับ 0–10 ก่อนเล่น (ไม่บังคับ) และหลังเล่นที่หน้าจบเกม หน้า "สถิติของฉัน" สรุปว่าหลังเล่นปวดลดลงเฉลี่ยเท่าไร ไม่ใช่การวินิจฉัยโรค
- **เตือนให้พัก** (9.5): ตั้งค่า → เตือนให้พัก เลือกทุก 30/45/60/90 นาที และช่วงเวลาทำงาน มีป้ายเตือนในหน้าเกม (เลื่อน 10 นาที / ปิดวันนี้ / เริ่มชุดท่าด่วน) และแจ้งเตือนของเบราว์เซอร์เมื่ออยู่แท็บอื่น (ต้องกด "อนุญาตการแจ้งเตือน") **ทำงานเฉพาะตอนเปิดหน้าเกมค้างไว้** ไม่รบกวนตอนกำลังเล่น
- **สำรอง/นำเข้าข้อมูล** (9.3): ตั้งค่า → "สำรองข้อมูล" ดาวน์โหลดไฟล์ JSON เดียว (ตั้งค่า ประวัติ ท่าที่สร้าง ค่าแผ่นเต้น บันทึกอาการปวด) นำเข้ากลับได้บนเครื่องอื่น ไฟล์ที่ผิดรูปแบบหรือมีคีย์แปลกปลอมจะถูกข้ามอย่างปลอดภัย
